The ovat/ package, grouped by folder. Pick a file to see what it does, why it is built the way it is, and what it works with. The bar under each name is its size in lines. Or press Follow one ovat run to watch a request move through the files in order.

Twelve stops, from the command line to the printed answer.

Pick a module on the left.

Most files are small

The same 48 modules by length. Forty are under 400 lines. The four long ones are the command line, the terminal UI launcher, its chat screen and the telemetry sources.

Line counts are wc -l at OVAT 1.1.1, the same numbers as the bars in the map above.

The rest of the repository

tests/

About 800 tests, no server needed. live tests need OVMS and rag tests need the embedder; both skip themselves. The UI is tested headless.

examples/

Runnable configs: minimal, rag, react, audio-multimodal, document-qa, document-qa-npu and plano. Each folder has its own README.

docs/

ARCHITECTURE.md, the design record; the workflow reference, generated from the schema so it cannot drift; and the walkthrough.

AGENTS.md

Contributor rules and the list of landmines: each one cost a whole session once, with the measurement that found it.

A visual guide to the OpenVINO Agentic Toolkit, a Google Summer of Code 2026 project for OpenVINO by Gurman (Lagmator22). Every fact here comes from the OVAT source and its design notes.

Built for Intel AI PCs: a Core Ultra CPU, an Arc GPU and an NPU. This is the Intel mark OVAT's own terminal UI shows.
